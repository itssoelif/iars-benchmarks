# Taillard PFSP instances (ta001–ta120)

120 permutation flow-shop benchmark instances from Taillard (1993), redistributed
unmodified. Every file was regenerated from its own published seed with Taillard's
portable `unif` generator (Park–Miller / MINSTD, a = 16807, m = 2^31 − 1) and matches
bit-for-bit: **120/120 reproduce**.

File name `tai{n}_{m}_{k}.fsp` maps to Taillard's `ta001`–`ta120` numbering by walking
the twelve size groups in the canonical order, ten instances each. `UB` and `LB` are
Taillard's published bounds, carried in each file's own header line.

Integrity: `SHA256SUMS` in this directory. Verify with

```bash
sha256sum -c SHA256SUMS
```

Cite Taillard (1993), https://doi.org/10.1016/0377-2217(93)90182-M — not this repository.
